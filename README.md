# 🏗 AI-ассистент строительного учёта (Telegram-бот для прораба)

Прототип интеллектуального Telegram-бота с AI (LLM), принимающего ежедневные дневные отчёты о выполненных работах на объекте в свободной форме (**текстом или голосом**) и синхронизирующего данные с **Google Таблицей** и **Битрикс24 REST API**.

Проект разработан в строгом соответствии с техническим заданием (на основе образца спецификации `Ежедневное_выполнение_Садик.xlsx`, разделы ОВ-3 и ЭМ3).

---

## 🌟 Ключевые возможности

1. **Приём отчетов в свободной форме (текст и голос)**:
   - Понимание разговорного строительного сленга («_медь 6-ка_», «_шестёрка_», «_кабель 3 на 2,5_», «_хомуты под фреон_»).
   - Разрешение контекстных ссылок («_изоляцию на них столько же_» — автоматически сопоставляет нужные диаметры изоляции и объемы).
   - Транскрибация голосовых сообщений (Whisper / Groq / OpenAI).
2. **Динамический справочник позиций**:
   - Справочник **НЕ зашит в код**, а динамически считывается напрямую из таблицы (Google Sheets или Excel). При добавлении новых строк в таблицу бот сразу их подхватывает.
3. **Неоднозначность и уточнение (без слепого угадывания)**:
   - Если позиция сформулирована неполно (например, «_поставили 10 хомутов_» без указания фреон/дренаж или «_кабель 50 м_» без сечения), бот **не угадывает**, а выводит удобные inline-кнопки с вариантами для выбора.
4. **Интерактивное подтверждение и редактирование**:
   - Перед записью мастер видит сводную карточку с суммами начисленной ЗП и предупреждениями.
   - Прямо в Telegram можно:
     - ✏️ Изменить объём любой позиции в 1 клик.
     - ➕ Добавить забытую работу.
     - 🗑 Удалить лишнюю позицию.
     - ❌ Отменить всё.
5. **Предупреждение о перерасходе по смете**:
   - Если указанный объем превышает сметный остаток (`к-во` минус `выполненный объем`), бот выводит предупреждение с точной цифрой перерасхода.
6. **Ответы на вопросы по остаткам**:
   - Мастер может спросить: «_сколько осталось по кабелю 3х2,5?_» или «_какой остаток по меди 6?_» — бот моментально выдаст сметный план, факт и остаток.
7. **Корректировка данных за сегодня (`/today`)**:
   - Мастер может просмотреть все объемы, уже внесённые за сегодняшний день, и скорректировать любое значение.
8. **Двойная синхронизация (Google Sheets + Битрикс24)**:
   - **Google Sheets**: автопоиск или создание столбца с текущей датой (`DD.MM.YYYY`), запись объемов напротив соответствующих строк спецификации, пересчет формул.
   - **Битрикс24**: создание структурированной Задачи с чек-листом позиций + публикация красивого отчета в Новостях (Живой ленте компании).
   - Кнопка с прямой ссылкой на таблицу и задачу сразу после сохранения.

## 🚀 Быстрый старт

### 1. Клонирование и виртуальное окружение

```bash
# Создание виртуального окружения Python
python -m venv venv

# Активация окружения:
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# Linux / macOS:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка файла `.env`

Скопируйте шаблон конфигурации:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:

```ini
# Токен бота Telegram (получите у @BotFather)
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ

# Ключ OpenAI (для LLM gpt-4o-mini и транскрибации Whisper)
OPENAI_API_KEY=sk-...
LLM_MODEL=gpt-4o-mini
WHISPER_MODEL=whisper-1

# Google Sheets
GOOGLE_SERVICE_ACCOUNT_FILE=service_account.json
GOOGLE_SPREADSHEET_ID=1A2B3C4D5E...
GOOGLE_WORKSHEET_NAME=Лист1
GOOGLE_SHEET_URL=https://docs.google.com/spreadsheets/d/1A2B3C4D5E.../edit

# Битрикс24 REST API (входящий вебхук)
BITRIX24_WEBHOOK_URL=https://your-portal.bitrix24.ru/rest/1/webhook_code/
BITRIX24_RESPONSIBLE_ID=1
BITRIX24_CREATE_TASK=true
BITRIX24_CREATE_FEED_POST=true
```

> **Примечание:** если у вас пока нет ключей Google или Битрикс24, бот автоматически работает в **автономном режиме** — считывает и записывает данные в локальный файл `Ежедневное_выполнение_Садик.xlsx` и эмулирует вызовы Битрикс24 без сбоев.

## 📊 Настройка Google Sheets за 2 минуты

1. Создайте Google Таблицу путем импорта файла `Ежедневное_выполнение_Садик.xlsx` (или откройте Google Диск -> Загрузить файл -> Открыть в Google Таблицах -> Файл -> Сохранить как Google Таблицу).
2. Создайте сервисный аккаунт в [Google Cloud Console](https://console.cloud.google.com/), включите **Google Sheets API** и скачайте JSON-ключ под именем `service_account.json` в корень проекта.
3. Скопируйте email сервисного аккаунта (`xxx@project.iam.gserviceaccount.com`) и в Google Таблице нажмите **Поделиться** -> добавьте этот email с правами **Редактор**.
4. Скопируйте ID таблицы из URL и вставьте в `.env`.

---

## 🏢 Настройка Битрикс24 (вебхук) за 1 минуту

1. Зайдите в ваш портал Битрикс24 (можно бесплатно создать на [bitrix24.ru](https://www.bitrix24.ru)).
2. Перейдите в левом меню: **Разработчикам** -> **Другое** -> **Входящий вебхук**.
3. В правах доступа отметьте:
   - **Задачи (tasks)**
   - **Живая лента / Новости (log)**
4. Нажмите **Сохранить** и скопируйте предоставленный URL вебхука в `BITRIX24_WEBHOOK_URL` в `.env`.
5. Проверьте работоспособность вебхука одной командой:
   ```bash
   python scripts/test_bitrix.py
   ```
